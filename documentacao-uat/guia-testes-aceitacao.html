1. Purpose of this document

This guide drives the acceptance testing (UAT — User Acceptance Testing) of the Symanek College system. The goal is to confirm, with real users and test data, that every module works as expected before final production acceptance.

Testing covers the following areas:

Public websiteManagement / admin Suite
  • Navigation and institutional pages
  • Programmes / courses
  • Application process
  • Application status check
  • Proof of payment upload (EFT)
  • Contact
  • Admin area and per-role permissions
  • Admissions management
  • Student management
  • Programmes / courses and capacity
  • Enrolments
  • Manual payments
  • Academic results
  • Official documents
  • Student portal and teacher portal

3. Testing rules

  • Use only authorised test data. Do not enter real personal data of third parties without authorisation.
  • Do not use real sensitive data (ID documents, real financial data) without explicit authorisation.
  • Record every issue found with: screenshot, date/time, user used, module and a description of what happened vs. what was expected.
  • Use the test accounts provided separately. In this document, accounts appear as placeholders: [admin email], [student email], [temporary password].
  • Do not consider production approved until Pedro Teixeira signs the sign-off page (section 8).
How to log a defect (quick template): Date/time · User · Module/page · Steps to reproduce · Actual result · Expected result · Screenshot attached (Y/N) · Severity (Critical/High/Medium/Low).

7. Go-live blocking criteria

If any of the items below occurs, production must not proceed until it is fixed and retested.
  • Login fails (a valid user cannot sign in).
  • Application does not persist (submission is lost).
  • Payment does not update the balance.
  • Enrolment falls into the waitlist improperly while a place is available.
  • Student sees wrong data (another student's or incorrect).
  • Incorrect permission (a role accesses something it should not).
  • Incorrect official document (wrong letter/certificate).
  • Wrong published result.
  • Any critical error without a fix.
