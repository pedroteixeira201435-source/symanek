Part 3 — System Audit: The School Admin

The School Admin now has full control of every module, as follows:

1. Application Component (student biographical information)

  • Admin can add new students.
  • Each student record has an Action button: Show profile, Update profile, Documents, Applications, Reset password, Log in as.

2. Admission

  • Manual Admission — list of students with application status and an Action button to process applications (advance or reject).

3. Registration

  • Modules registration · Qualification management · Modules management · Student Blocks (place/release holds).

4. Students' Marks

  • My Modules (per lecturer).
  • Marks Suppression by academic year and intake, choosing which marks to suppress (CA / Exam / Final).
  • Module Allocation — allocating modules to teaching staff.
  • Control access, assign permissions and block staff access (role permission matrix + activate/deactivate).

5. Documents (previously missing)

  • Examination permit · Proof of registration · Academic records · Student letters (admission / rejection) · Statement of results — all generated as official, printable documents on the college letterhead.

6. Settings

  • Previously empty — now includes institution profile, academic calendar, module toggles, role permissions, user accounts, and the academic control windows above.
